# 全記事を通じた教訓

本人が複数の記事で繰り返し語ること、または後年に過去の経験を振り返って明示したことを整理する。下記は本人の主張であり、読者への個別の金融・法律・医療助言ではない。

FIRE後に働くことは失敗ではない。資産と少しの収入を組み合わせるSide FIREの方が、生活の安全と選択肢を両立しやすいという方向の考えが強い。
