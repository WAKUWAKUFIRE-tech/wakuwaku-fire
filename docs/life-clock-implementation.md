# FIRE人生時計 — Phase 1 実装報告

新規URL: `https://wakuwaku-fire-git.pages.dev/life-clock/`

対象: `WAKUWAKUFIRE-tech/wakuwaku-fire`。HTML・CSS・JavaScriptのみで動作し、アプリのビルドと追加ライブラリは不要です。データベース、ログイン、既存のFIRE QUESTとは独立しています。

## 実装した体験

- 初回は紹介と「あなたの人生残高を計算する」。次に年齢・金融資産・年間生活費・想定利回り・平均寿命の目安・健康寿命の目安の6項目を表示。
- 添付のモバイルカードを参考にした赤・黄色基調の「あなたの残り時間」を最上部に表示。平均寿命／健康寿命のタブで残り年数・残り日数・年日時計を切り替えられ、人生の消化率は表示しない。
- 健康人生残高、残り年月、運用を考慮した日々の人生予算、資産寿命、平均寿命の目安時資産。
- 資産グラフは現在地、健康寿命、平均寿命の目安、範囲内の資産ゼロ地点を表示。範囲外の資産ゼロ年齢も文章で表示。
- 桜・夏・誕生日・旅行・ラーメンの概算体験回数。独自イベントの年／月頻度、追加・確認付き削除。
- 今日の人生ログ、登録数としての思い出資産、+1演出、過去ログの追加表示。
- 再訪時のダッシュボード復元、経過日数のメッセージ、日付による残高更新、複数タブの変更反映。
- ホーム・資産・人生ログ・設定の下部ナビ、設定の変更、全削除の確認。
- 「残りの夏」だけのシェア。Web Share API、コピー、手動コピーの順でフォールバック。共有は利用者が押したときだけ。
- SEO本文、注意事項、canonical、OGP、サイトマップ、専用アイコンとホームページからの入口。

## 計算方法

金額は内部では円。年利 `r` を `i = (1 + r)^(1/12) - 1` の月利に変換し、毎月末に年間生活費の1/12を取り崩します。資産寿命は同じ等額取り崩しモデルの残高ゼロ交点を求め、月未満を補間した年数です。利回り0は `資産÷年間生活費`。運用益が支出を補う条件は「尽きない計算」と明示し、将来の保証と区別します。資産0は即時0。資産が尽きた後のグラフは0で固定し、負債や不足額は推計しません。

人生予算は年利を日利に変換した定額取り崩し額です。利回り0では `資産÷残り日数`。健康寿命以降の費用を確保する額ではないことをカード内でも説明します。

寿命カードの残り日数は `calculateRemainingDays(年齢, 寿命の目安, 経過日数)`、すなわち `max(0, ceil((寿命の目安−入力年齢)×365.2425)−入力日からの経過日数)` で求めます。平均寿命と健康寿命は同じ計算を表示タブで切り替えます。最終日の端数も1日とし、0未満にしません。日付入力がないため誕生日の厳密な日付計算ではありません。体験は `floor(残り日数÷365.2425×年間頻度)` の概算です。資産は最後に入力した額を現在の残高として使用し、実際の増減を自動で推測しない旨を明記しました。年齢を変えず条件だけ編集した際には年齢の基準日を維持します。

税金・年金・収入・インフレ・手数料・リターンの変動は含めません。医療情報から寿命を推測する処理はありません。

## 保存内容とプライバシー

キーは `wakuwaku.life-clock.v1` のみ。スキーマバージョン、6入力値、表示中の寿命タブ、年齢基準日時、最終更新日時、独自イベント（ID・名前・頻度・年/月）、人生ログ（ID・本文・日時）、前回訪問日時を保存します。思い出資産はログ件数から導出します。入力値をURLに含めません。

読み込み時にスキーマを検証し、破損・未知バージョンは上書きせず復旧案内を表示。容量不足などの保存失敗時は変更を確定せず、保存できなかった旨を表示します。リセットで他ツールのキーを削除しません。端末変更・ブラウザデータ削除による記録消失には対応していません。

外部Analytics送信は **0件**。将来の連携用にブラウザ内の `life-clock:event` カスタムイベントだけを用意しています。`detail` はイベント名のみです。

- `life_clock_start`
- `life_clock_calculated`
- `life_event_added`
- `life_log_added`
- `pwa_install_clicked`
- `share_clicked`
- `return_visit`

送信しないもの: 金融資産、生活費、利回り、年齢、寿命、イベント名、ログ本文、個人ID。現段階では匿名イベントもサーバーに送りません。既存サイトのAnalyticsやAdSenseを人生時計の操作面には読み込まず、CSPも同一オリジンに制限しています。後から計測を接続する場合も個別入力値を引き渡さないことが必須です。

## PWA

専用manifest、192/512pxアイコン、512px maskableアイコン、180px Appleアイコン、standalone、theme/background colors、専用start_url/id/scopeを設定。ページ・CSS・JS・アイコンをキャッシュしてオフライン起動と記録に対応しています。初回オンライン起動とService Workerの準備完了が必要です。

ホームページ用Service Workerは人生時計への介入だけを除外。人生時計側は `/life-clock/` のリクエストだけを処理し、自分のキャッシュ名前空間だけを更新します。アップデートは旧タブ終了後に適用し、開いている画面に新旧コードを混在させません。**アプリファイルを更新する際は `life-clock/sw.js` のCACHE定数も更新してください。**

Android/Chromeは利用可能な場合にinstall promptを使用。iPhone/iPadはSafariの「共有→ホーム画面に追加」を案内。インストール済みはCTAを非表示。
