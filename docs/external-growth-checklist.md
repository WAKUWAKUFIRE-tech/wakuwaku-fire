## RSSとサイト側の運用

- [ ] 本番の `feed.xml` がHTMLの404ではなくRSS XMLとして表示される。
- [ ] タイトル・URL・公開日時・概要・サムネイル・カテゴリが取得できる。
- [ ] 次回記事公開後、RSSに新しい記事が追加される。未来日時やnoindex記事が入らない。
- [ ] 外部サービスで記事・画像が取得される（サービス側の反映には時間差あり）。
- [ ] X・LINEは共有画面まで確認し、投稿する場合は本人が最終内容を確認。URLコピーも確認。

`npm run build:growth` で既存記事の共有案内・関連記事・メタデータ・RSS・sitemapを再生成します。記事自動公開処理と失敗時の復元処理にも接続済み。手作業で記事を追加・変更した場合は公開前に同コマンドを実行してください。RSSは1本のみです。

URLを空にすると非表示。URLだけを設定すれば表示され、休止時は `enabled: false` にできます。今回のランキング対応はブログ村のみです。HTTPSの公式ドメインのURLを受け付けます。トップにはランキングを出しません。将来の掲載実績は同ファイルの `externalRecognition` に追加する構造です。
